# SuperAsk.AI — Demo 1 slides

The CSCI 441 Demo 1 presentation, 20 slides, published with GitHub Pages.

- **Present online:** https://bunkheang-heng.github.io/superask-slides/
- **Download PDF:** https://bunkheang-heng.github.io/superask-slides/SuperAsk-Demo1.pdf

**Keys while presenting:** `→`/`←` or click to move · `F` full screen ·
`S` presenter view (notes, next slide, timer) · `G` overview · `D` download PDF ·
`?` all shortcuts.

## Files

| File | What it is |
|---|---|
| `index.html` | The presentation: all slides plus the player. Generated — don't edit by hand. |
| `SuperAsk-Demo1.pdf` | All 20 slides, one per page. |
| `<id>.html` | One slide each (1920×1080), speaker notes in the `<aside>`. |
| `deck.json` | Slide order, sections and fonts. |
| `build.py` | `python3 build.py --pdf` rebuilds `index.html` and the PDF (Chrome needed for the PDF). |

The source of these slides is [`docs/demo-1/slides/backup/`](https://github.com/Monunhh/Super-ask/tree/main/docs/demo-1/slides/backup)
in Monunhh/Super-ask. To update this site, copy the changed files here,
rebuild, and push — GitHub Pages republishes within a minute or two.
