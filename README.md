# SuperAsk.AI — Demo 1 slides

The CSCI 441 Demo 1 presentation, 5 slides (overview, roadmap, the live-demo
plan and the plan for the rest of the semester), published with GitHub Pages.

- **Present online:** https://bunkheang-heng.github.io/superask-slides/
- **Download PDF:** https://bunkheang-heng.github.io/superask-slides/presentation_slides.pdf

**Keys while presenting:** `→`/`←` or click to move · `F` full screen ·
`S` presenter view (notes, next slide, timer) · `G` overview · `D` download PDF ·
`?` all shortcuts.

## Files

| File | What it is |
|---|---|
| `index.html` | The presentation: all slides plus the player. Generated — don't edit by hand. |
| `presentation_slides.pdf` | All 5 slides, one per page. |
| `cover.html`, `intro.html`, `roadmap.html`, `demo.html`, `next.html` | One slide each (1920×1080), speaker notes in the `<aside>`. |
| `deck.json` | Slide order, sections and fonts. |
| `build.py` | Builder from the source repo. |

The source of these slides is [`docs/demo-1/slides/`](https://github.com/Monunhh/Super-ask/tree/main/docs/demo-1/slides)
in Monunhh/Super-ask. To update this site, copy the changed files and the PDF
from there and push — GitHub Pages republishes within a minute or two.
